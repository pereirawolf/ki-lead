# Ergebnisse

Zusammengefasste Bewertungen nach `../bewertungsschema.json`, je Datei eine Bewertung (`<fall>_<kennung>.json`) oder eine Liste von Bewertungen (`<fall>_<planfassung>.json`, JSON-Array).

Nicht hierher: Laufprotokolle mit Rohantworten, Artikeltexte, Material Dritter, API-Schlüssel. Diese bleiben verschlüsselt oder im nicht eingecheckten Ordner `privat/`.
